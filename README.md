# abcZhongwen - Traductor Multiidioma a Chino Mandarín

**Español o Inglés a Chino Mandarín by joseAlejandro**

Una aplicación web interactiva que permite escribir mensajes en español o inglés y visualizar su traducción automática al chino mandarín simplificado con efectos visuales y sonoros únicos.

## 🌟 Características Principales

### 📝 Traducción Automática
- **Traducción en tiempo real** de español a chino mandarín simplificado
- **Diccionario local** con más de 100 palabras comunes
- **API de respaldo** para traducciones más precisas
- **Visualización simultánea** del texto original y traducido

### 🎨 Visualización Interactiva
- **Efectos visuales únicos** para cada carácter
- **Tres modos de visualización**:
  - **Secuencial**: Caracteres aparecen uno tras otro
  - **Cascada**: Aparición rápida en cascada
  - **Explosión**: Aparición aleatoria tipo burst
- **Partículas y conexiones** entre caracteres
- **Paletas de colores personalizables**

### 🔊 Audio y Voz
- **Sonidos únicos** para cada carácter basados en frecuencias musicales
- **Reconocimiento de voz** en español
- **Armonía cronológica** que crea melodías mientras escribes

### 💾 Gestión de Mensajes
- **Historial automático** de mensajes y traducciones
- **Reproducción** de mensajes guardados
- **Exportación** y compartir mensajes
- **Persistencia local** de configuraciones

## 🚀 Instalación y Uso

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexión a internet (para API de traducción)

### Instalación
1. Clona o descarga el proyecto
2. Abre `index.html` en tu navegador
3. ¡Comienza a escribir en español!

### Uso Básico
1. **Escribe** tu mensaje en español en el campo de texto
2. **Observa** la traducción automática aparecer arriba
3. **Disfruta** los efectos visuales y sonoros
4. **Guarda** mensajes importantes con el botón 💾
5. **Comparte** con el botón 🔗

## 🌐 API de Traducción

Utiliza la API gratuita de MyMemory como respaldo:
- **Endpoint**: `api.mymemory.translated.net`
- **Idiomas**: Español (es) → Chino Simplificado (zh-CN)
- **Fallback**: Diccionario local si la API falla

## 🎵 Sistema de Audio

Cada carácter tiene una **frecuencia musical única**:
- **A**: 261.63 Hz (Do)
- **B**: 293.66 Hz (Re)
- **C**: 329.63 Hz (Mi)
- Y así sucesivamente...

Esto crea **melodías únicas** para cada mensaje.

## 🐛 Solución de Problemas

### El reconocimiento de voz no funciona
- Verifica que tu navegador soporte Web Speech API
- Asegúrate de dar permisos de micrófono
- Funciona mejor en Chrome y Edge

### La traducción no aparece
- Verifica tu conexión a internet
- La traducción local funciona sin internet
- Espera unos segundos para la API

### Los sonidos no se reproducen
- Haz clic en cualquier parte de la página primero
- Algunos navegadores requieren interacción del usuario
